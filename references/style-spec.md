# 已确认的双风格拓扑样式

可选 `2.5d` 和 `rounded`，后者是与 2.5D 同批比较的 Ops 方案 A「精修色块图符」。两套设备语义一致，均使用下面的布局和标注规则。

## 视觉参数

这些值是常见起点，画布与间距随内容调整，不强制所有图同尺寸。

| 元素 | 常用值 |
| --- | --- |
| 背景 | 白色 |
| 分区 | `#fbfcfd` 填充、`#dce4ea` 细边框，圆角约 18px |
| 有线链路 | `#626a72`，约 2.3px |
| 绿点 | `#2b9d48`，半径约 4.7px，白色细边 |
| 设备与端点间隙 | 约 16px，设备下方有阴影时适当增加 |
| 接口编号 | `#35424c`，15px 左右、较粗，靠近本端绿点 |
| 设备名称 | `#151c22`，20px 左右、较粗 |
| 名称留白 | 同组使用统一标注带，距设备包络至少约 16px |
| IP、VLAN 等 | `#6c7887`，14–17px；独立信息区 |
| 无线 | 淡紫色虚线，无物理绿点 |

设备按所选风格复用 32 类图标。网络设备按家族着色，终端灰色，服务器绿色，安全设备橙色，无线紫色。2.5D 的 AP 是吸顶朝下造型，机框交换机顶面用平行反向箭头；圆角采用白色抽象设备符号、渐变底块与顶部高光，保留原 A 方案的八个基础图符并扩展其余设备。

## 位置决策

最终取景以完整内容范围为准，包括阴影和文字；默认四周等距留白。不能把 root viewBox 原点改成零而丢失自动取景，也不能只因图标中心看起来对齐就忽略接口名、IP 造成的左右视觉偏移。

先定链路与端点，再定接口编号，再按组安排名称，最后排其他信息。直接斜线是合法且常用的；折线只在确有避让需要时使用。多个接口分别走独立线路，不能用总线替代。

斜线首尾按设备方向与轮廓交点确定，沿线保留约 16px 可见间隙。文字保持水平，围绕端点集中安排并检查整组碰撞，不能仅把横向标签向上或向下推。分层布局同层使用统一的目标角度；多终端布局左右外侧展开范围相同，数量不同时也保持成组协调。

名称仅用八个方位，下方优先；同排或同层级尽量统一方位。整组下方不可用时，先尝试整组上方及其他方位。不要为统一名称方向而破坏连线质量；八方位均不可用时扩大空间或调整整体布局，不能悄悄绕线。

有无 IP/VLAN 时，同一拓扑的接口位置应相同。IP 是端口属性时在线旁保持端点归属；终端单接口 IP 可放设备名附近。VLANIF、路由子接口等使用其真实逻辑接口名称，不错贴到物理口。

OSPF 的区域边界应反映接口实际归属；ABR 的两侧不能仅用设备名称在框内代替端口关系。多条聚合成员保留各自两端接口；逻辑聚合名作为组标签，不额外画出不存在的第五条物理链路。

示例中使用的画布大小和设备比例不必照搬。拥挤时优先增加间距，不把接口文字缩成无法阅读的小字。
